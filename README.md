# 💳 Credit Card Fraud Detection

A machine learning project that detects fraudulent credit card transactions using **XGBoost**.  
The project includes a **Streamlit web app** for interactive predictions.

---

## 🚀 Features
- Detects fraud in real-time using 30 transaction features
- Handles **imbalanced dataset** with undersampling / SMOTE
- Model evaluation using Accuracy, Precision, Recall, F1-score
- Probability output for fraud prediction in the web app
- Interactive **Streamlit dashboard**

---

## 🧠 Tech Stack
- Python 3
- Pandas, NumPy
- Scikit-learn
- XGBoost
- Joblib (for saving model)
- Streamlit (for web app)

---

## 📈 Dataset
- Credit Card Fraud Detection dataset from [Kaggle](https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud)
- 284,807 transactions, 30 features, highly imbalanced (~0.17% fraud)
